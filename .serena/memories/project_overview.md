Purpose: pi-extensions is a monorepo of independently installable Pi coding-agent extension packages published under @bacnh85/. There is intentionally no root npm package. Each package has its own package.json, extensions entrypoint, optional skills/hooks, README, and node_modules. Main stack is Node.js, TypeScript ESM extensions, Pi ExtensionAPI, TypeBox/tool schemas, Mocha+tsx tests; pi-ponytail uses plain JavaScript and Node's built-in test runner. Evidence: root README.md and package manifests.
